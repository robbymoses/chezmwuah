# Starship theme examples

These are alternative complete Eldritch prompt configurations. They are not
loaded automatically; `../starship.toml` is the active configuration.

| File | Style |
| --- | --- |
| `colors.toml` | shared Eldritch palette |
| `eldritch-spaceship.toml` | icon-rich, two-line Spaceship-style prompt |
| `eldritch-pure.toml` | minimal Pure-inspired prompt |
| `eldritch-powerline.toml` | segmented Powerline-style prompt |
