# XDG configuration

This directory maps to `~/.config`. Each application keeps its configuration
and its explanation together:

| Directory | Target | Documentation |
| --- | --- | --- |
| `zsh/` | `~/.config/zsh/` | [Zsh](zsh/README.md) |
| `starship/` | `~/.config/starship/` | [Starship](starship/README.md) |
| `ghostty/` | `~/.config/ghostty/` | [Ghostty](ghostty/README.md) |
| `hypr/` | `~/.config/hypr/` | [Hyprland](hypr/README.md) |
| `noctalia/` | `~/.config/noctalia/` | [Noctalia](noctalia/README.md) |

These README files describe source state only; `.chezmoiignore` prevents them
from being installed into `~/.config`.
